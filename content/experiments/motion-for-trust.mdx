## Why continuity matters

When an interface changes state, motion can show that the new thing came from the old thing. That continuity is especially useful in high-consideration experiences, where an unexplained jump can make the system feel unpredictable.

This experiment uses one object, one spatial move, and one change in shape. There is no decorative entrance or duplicated layer.

The easing accelerates quickly and spends more time settling. That keeps the response immediate while giving the eye enough time to follow the transformation.

## Design constraints

<Callout>
  Motion should preserve context, not call attention to itself. If the transition does not explain a relationship, it probably does not need to be there.
</Callout>

- Keep the origin and destination visible.
- Avoid overlapping transitions with different meanings.
- Prefer a single continuous object over a crossfade.
- Let timing follow the distance traveled.

## Accessibility

The site honors the operating system’s reduced-motion preference. With reduced motion enabled, the same state change happens almost instantly, with no loss of information or control.
